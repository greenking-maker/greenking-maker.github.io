# 基于古籍理论的中药药对检索数据库
A web-based database of traditional Chinese medicine herb pairs derived from classical literature.

---

## 📌 项目简介
本数据库以《神农本草经》《伤寒论》《金匮要略》《本草纲目》等中医经典古籍为依据，整理收录了经典中药药对信息，可用于中药配伍规律研究、分子配伍设计及中医药新药研发前期筛选。

## 🔍 数据库字段说明
| 字段 | 说明 |
| :--- | :--- |
| ID | 药对唯一编号 |
| 药物A/B | 药对组成药物（采用《中国药典》标准正名） |
| 古籍出处 | 药对来源的经典古籍 |
| A/B性味 | 药物性味（按古籍原文及药典规范整理） |
| 七情配伍 | 相须、相使、相畏、相杀、相恶、相反 |
| 君臣佐使 | 药对在方剂中的角色定位 |
| 传统功效 | 古籍记载的主要功效 |
| 主治病证 | 对应治疗的病证 |
| 配伍禁忌 | 是否属于十八反/十九畏禁忌 |
| 核心活性成分 | 药对主要药效物质基础 |
